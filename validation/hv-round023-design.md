`★ Insight ─────────────────────────────────────`
- A1 and A6 share one lesson about ordering guarantees. The design's strongest pattern is verify-and-consume at the serialized commit, which closes time-of-check to time-of-use gaps because the commit re-validates. An Admission that is dispatched without a recheck is the inverse: a stored decision whose preconditions can change in flight. The fix is cheap, one dependency and one dynamic-view step, but it must be in the model that implementers read.
- A2 is not a design philosophy problem but a layering omission. The section 2 table already defines a dependency-free bridge.domain project; the crosswalk simply never uses it. Moving the interfaces there dissolves every cycle without changing any class responsibility.
