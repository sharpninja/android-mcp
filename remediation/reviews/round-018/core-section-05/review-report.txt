`★ Insight ─────────────────────────────────────`
- Each `@startuml` block is an independent PlantUML namespace, so a class named `AdmissionGate` in two blocks is two unrelated definitions to the renderer. Consistency across blocks exists only by convention, which is why CS05-04 asks for one defining block per class and explicit `<<from component>>` stubs elsewhere.
- Declaring "composition diamonds denote owned lifetime" turns every missing diamond into a statement that nothing owns that object. The legend is what makes CS05-02 a defect rather than a stylistic gap.
- Structurizr image views attach to exactly one element, so a code block that spans three components cannot be mapped without choosing one. Splitting blocks per component is cheaper than inventing an umbrella element.
