`★ Insight ─────────────────────────────────────`
- An ETag is a validator for one resource's representation. Folding a store-wide generation counter into it makes every unrelated write look like a conflict, so optimistic concurrency silently degrades into a global lock.
- "Sorted-key compact JSON" is not a canonical form. Python sorts keys by code point while RFC 8785 sorts by UTF-16 code unit, and float rendering differs per language, so a Kotlin reimplementation can hash the same document differently.
- A `.proto` file proves field tags, enums and defaults, but not runtime behavior. Framing limits, version strings and whether a field like `max_frames_per_second` is enforced live only in the host code.
