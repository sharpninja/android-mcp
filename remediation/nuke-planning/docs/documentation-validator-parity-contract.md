# Native document validation parity

This increment is pending. It does not inherit the pure UI renderer, package ZIP or Architecture002 runtime proofs. The one native validator must cover both the retained Gradle verifyDesignDocs clauses and `tools/check_documentation.py` from the publication source. The latter source was read as text; no legacy command ran.

Keep one artifact-based validation service and explicit validation profiles. BeforeManifest validates the generated source/artifact union without requiring a checksum output that has not been produced. AfterManifest additionally validates every admitted checksum line against the exact artifact bytes. Profiles preserve the differing old link policies instead of silently treating one old checker as the complete contract.

The required clauses are:

- Derive the complete docs SVG path set from the existing architecture-view authority and UI manifest/canonical model. Compare the exact set, not a minimum count. Current full denominator is 221 docs SVGs; 17 compatibility copies outside docs make the combined generation total 238 SVGs. These numbers describe current fixtures, not hardcoded validator tables.
- Parse every docs SVG with external entity resolution disabled. Require the SVG root/namespace and vector text. Reject raster images, scripts and stale embedded renderer SRC metadata, preserving the existing generation checks. Retain all per-file parse diagnostics.
- Check every included current Markdown relative link. The retained Gradle policy checks file targets in its docs/contracts/README/storyboards/code source set. The repository checker examines all Markdown outside .git, percent-decodes targets, ignores any URI scheme, and accepts existing directory targets. Preserve these scopes as explicit profiles. Fragment-only links are excluded; local paths remain confined to the admitted artifact namespace. Never fetch a remote link.
- Reject obsolete current diagram source fences through the same current-source policy. Historical fixture content is a separately admitted historical class, not silently omitted by basename.
- Verify each editable ui-svg copy has its corresponding docs/screens artifact and identical bytes. Derive the 17 pairs from canonical manifest roles, not a second screen/storyboard range table.
- Parse the offline HTML assets for script, img, link, iframe, video and audio start tags. For src/href attributes reject http:, https: and protocol-relative references, preserving the original case behavior where applicable. Also preserve the Gradle external CSS url checks and SVG-image embedding/image-count checks. Use the existing shared HTML decoding authority where decoding is required; do not copy an entity table or use a browser/Node process as a parser.
- AfterManifest validates all checksum lines, target existence and exact shared hash results, with a clear duplicate/path/malformed-line policy tied to the existing package checksum contract. The manifest excludes itself. Source/artifact receipts and IContentHash remain the common authorities.

Mock fixtures must include one complete admitted current corpus, minimal contract-derived positive fixtures, each missing/unexpected SVG, malformed XML/DTD, vector/raster/script/SRC controls, each broken file/directory/percent-escaped/scheme/fragment link, every differing/missing copy, each of the six HTML asset tags and external reference forms, CSS URLs, missing/mismatched/malformed checksums, exact counters, diagnostic order and unchanged inputs. Every assertion gets its own incorrect-response control before native implementation. The same cases bind the real artifact-only service, then the Design/DocsVerify and Validate/Design adapters, followed by actual full-corpus invocation.

No public Design Validate alias duplicates Validate/Design. Generation uses the same service internally. Filesystem enumeration and namespace routing belong to the shared admitted source collector; the validator does not create a second path resolver, filesystem loop, hash implementation, stage graph or source model.
