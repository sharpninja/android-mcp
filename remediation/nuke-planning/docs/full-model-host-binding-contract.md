# Minimal full-model architecture host binding

`staging/Build.Architecture.full-model.cs.pending` is a proposed replacement for the existing host partial, not a copied or compiled app change. It consumes the proven full recipe, selected source authority, collector and Core runtime. The original six-input recipe/provider tests remain unchanged.

The existing `Design/Architecture` parameters remain required: project/output/cache/work/receipt roots, Docker identity, renderer user and tool access. Generation and offline Gradle checksum proof remain optional. Root must add one optional `CatalogRoot` string property and register `catalog-root` in the same operation definition. Its default is the normalized project sibling `../catalog`. The current source-pin contract names exactly that sibling, so the proposal rejects a supplied different base rather than inventing root rebasing or another route validator. Root owns the parameter/host admission mock proof before copying this partial. Existing shared path confinement handles directory/symlink safety.

The host captures the 12 required inputs and three optional canonical observations once through `DocumentationSourceCollection`. Missing optional originals remain explicit null observations. It derives the jar/profile context from captured locks, binds the native model reader/projector/contract validator/module validator, and selects `generateArchitectureDiagrams` through the existing Core stage planner. The existing factory overload supplies required source identities and the collector's commit-time recheck to the same artifact runtime. There is no extra file enumeration, hash implementation, parser, lease loop or stage graph.

Expected normal output scope is 250 artifacts: 222 UI/deck artifacts, 27 architecture artifacts and the source-observation receipt. The generation manifest is committed last. Actual full-host execution, general DocsVerify and Gradle delegation are not established by the nine pure factory tests. Root should run the new host in fresh final/work/receipt roots after host admission proof, then verify manifest identities, full model validation, unchanged sources and existing browser/vector assertions.

This binding selects only the historical full architecture alias. It must not map extraction-only, Tools-only, UI-only or export-only Gradle requests to the complete 12-input/250-output operation. Those requests continue to use the authoritative selected stage union and existing native subset semantics. The GeneratedDesign selected catalog exposes 15 project inputs only for the future DocsVerify source closure; the ordinary Model catalog remains nine, with 12 required and three optional model observations.
