# Documentation legacy parity ledger

This is a migration ledger, not an acceptance receipt. All entries trace to hashes and exact method names in `saved-fixture-inventory.json`. The acknowledged 8,706-case entry gate precedes production. The first real gate in `evidence/ui-deck-real-gate.json`/`.trx` passes 2,721 total cases, including 2,637 documentation projection assertions and determinism cases, with zero failures or unexecuted cases. Browser layout and subsequent services remain pending. No pending entry below is retired or declared equivalent on the strength of a test count.

The public categories and singular operation registry own all dispatch. Internal services listed here share the sole NUKE application. Gradle aliases and historical script names never create a second graph or a public target per script.

## Completion rule

Before retirement, each INV/MOD/ARCH/TOOL/FACTOR destination needs approved requirements, frozen fixtures and assertions, passing correct mocks plus individually rejected negative controls, parent acknowledgement, real implementation binding and full zero-failure/zero-skip gate receipts. The UI label alone is not enough for any split method. The final source/tooling inventory must show no active Python/Node fallback, and the registry-generated operation map must point every supported old entry to the sole native graph or explicitly retained non-executable history.
