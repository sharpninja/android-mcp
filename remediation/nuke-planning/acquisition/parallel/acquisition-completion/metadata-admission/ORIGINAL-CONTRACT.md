# External canonical metadata input admission

Root authorizes this separate continuation. Prior ArchiveReuse5, Snapshot5 and normalization7 handoffs remain immutable and independently mergeable. This adapter adds no live source retrieval, receipt/archive parser fork, XML parser or transport.

Original `restore_snapshot.main` resolves the inventory file then uses its parent for raw targets, `transport.metadata_receipt`, and fixed `repository2-3.xml`. It selects downloaded rows, first per Git blob, verifies existing targets, and returns from default dry-run before reading these proof files. Only an explicitly downloaded missing bounded metadata row invokes restore_metadata. Its read/error order is receipt JSON, indexed lowercase etag, row platform OR legacy transport.platform_api_version, XML, exact package match, size, then version-bound ranges. An absent package_path defaults to platforms;android-<platform>; explicit null/nonstring does not default. Selected metadata is cached per archive URL by the caller; native reuse additionally binds immutable version/profile pins.

The actual release011 recipe's6 bounded rows refer to external receipt paths and omit inline etag/XML. Inspection receipt `20261028T2346018204637-recipe-field-inspection.json` records exact paths/platform/default facts without reading corpus payloads. Generic rehydration intentionally skips this canonical proof requirement and retains its explicit compatibility profile.

Publication owns an additive per-row MetadataReference projection from its one PlanCore walk, proposed in `RehydrationCanonicalMetadataReference.cs.proposed`. It captures receipt-path presence/kind, original platform precedence, and package presence/kind. No consumer parses OriginalRow. Missing facts are deferred to the caller so dry-run/exact-existing reuse retain their behavior. Existing Plan/PlanSeed wires stay unchanged.

Acquisition's minimal reader accepts the exact typed reference plus explicit caller StoredArtifact pins through an existing root-bound IPinnedArtifactReader. It reads the referenced receipt first, obtains only etag through the shared JSON stack, reads fixed XML, and calls the existing SdkArchiveVersionValidator. XML package/size/DTD behavior stays in that sole validator. A narrow typed package-choice overload may be required to distinguish absent default from explicit null without a second XML parser. Existing validator overloads/defaults remain unchanged.

The result overlays ETag, repository bytes, original platform/package choice and resolved archive size on the typed SourceArchivePin. It preserves member URL/hash/profile and unrelated prerequisites. Evidence records both local input pins and their admission scope. A local SHA proves the input bytes supplied by the caller; it does not independently establish official Google authority, archive whole-byte identity, source availability or API completeness.

Native proof-root defaults to the same raw/output root, matching the original inventory-parent data root. An explicit different proof-root is a caller store binding, not a recipe path prefix or an unpinned fallback. ProjectRoot remains the immutable recipe/code input root. Root owns any thin CLI parameter/workflow-envelope composition. Dry-run, exact existing reuse and Generic perform zero external-proof reads. All missing Canonical proof dependencies are admitted before the existing batch starts effects; this retains the native preflight contract while reporting original per-proof read/error ordering. No output or sealed receipt is written on failed admission.

Mock-first coverage must include all input identity/path/type/presence/read-order checks, row-vs-transport/default package behavior, malformed JSON/XML, missing/mismatched pins, local authority labeling, exact-target/dry-run/Generic bypass, shared proof reuse, strict range requests and failed-seal retention. SAME cases bind to the existing reader/validator/acquirer after green controls. Whole restore/fetch closure stays open until native caller/CLI and these external boundaries have normal evidence.
