These pins refer to frozen018 source, not a guessed runtime version.

Original current(kind) computes contract2 from the kind, Python major/minor, installed tree-sitter/tree-sitter-java or Expat version, and exact selected producer Python code hashes, including itself. It rejects unsupported kinds, caches up to two calls with lru_cache, and its module entrypoint prints the returned fingerprint. Those runtime/library/code values describe a historical Python producer. They must not be synthesized as C# identities.

The existing native SourceCache fingerprint hashes contract3 with language=csharp, explicit runtime identity, kind, producer, profile and ProducerFiles code pins through the sole canonical JSON service. RecipeSha256 and SourceSha256 are checked separately as immutable receipt identity fields; they are not additional fields in that fingerprint expression. Native cache data/sidecar hashes, record bytes/counts, changed identities and strict historical-byte refusal have normal evidence. Native generic cache-kind admission is not represented as the original two-kind current(kind) wrapper.

HistoricalSourceCache separately admits trusted historical kind/hash/count/producer pins for java-source and sdk-api-index and refuses unsupported kinds. It verifies existing historical bytes/records; it neither executes the old producer nor reconstructs Python/library/code fingerprints. Historical admission and native new-generation publication remain distinct responsibilities.
