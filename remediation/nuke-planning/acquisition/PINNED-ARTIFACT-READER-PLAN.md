# Shared pinned byte admission

Root assigned exact new Core/PinnedArtifactReaderContracts.cs and implementation plus Tests/Core/PinnedArtifactReader* ownership. No existing Core file is edited. Existing ArtifactReceiptVerifier only compares a described artifact to a complete receipt after bytes exist; it is not a caller-pin metadata validator. TestBuildPlanAdmission's private hash predicate is task-specific and accepts a different case convention. No shared caller-pin validator was found in Core.

The byte reader is bound to an admitted IArtifactStore. Before I/O, a caller pin must be nonnull, have nonnegative Length and a canonical lowercase 64-hex SHA256 matching native StoredArtifact output. Malformed pins fail ARTIFACT_PIN_METADATA with zero reads/writes. The store remains the path/root authority; this helper does not introduce another path resolver or infer a root. MediaType is descriptor data for the domain consumer, not a byte codec. Domain JSON readers continue to require application/json.

For well-formed pins: propagate cancellation, perform exactly one store ReadAsync with the identical path/token, compare length, then shared ContentHash.Sha256. Fail ARTIFACT_PIN_LENGTH before hash mismatch when both differ. Fail ARTIFACT_PIN_HASH for stale/different bytes. Missing and cancellation exceptions propagate. Return the exact admitted bytes; never parse JSON, reopen files, retry, write, fetch, or self-generate a trusted pin from editable bytes.

The original 20 mocked cases prove byte/empty/non-JSON admission, stale bytes, wrong digest/length, ordering, missing and cancellation with discriminating effects/arguments/payload/error controls. The additive 16 mocked cases prove null pin, negative length, missing/wrong-length/non-hex/noncanonical digest rejection before any I/O. Native implementation must wait until both mock groups pass, then bind the same 18 scenarios through the shared fixture/assertions. These fixture counts are not whole-project coverage claims.

SourcesInventoryReader will consume typed expected Publication projection plus caller-pinned inventory artifact through this reader, canonical JSON authority and the exact existing SourceBatch ResumeOnly verifier. It returns portable verified receipt/pins. The host must supply the raw acquisition root explicitly; it cannot be inferred from the inventory artifact's root. Catalog's pure bridge keeps OriginalRow bytes unchanged and receives selected eligibility/native statuses separately. SourceExtract's private pinned JSON read can later delegate to this shared byte helper under its own mock/native gate. No competing integrity path or cache codec is introduced.
