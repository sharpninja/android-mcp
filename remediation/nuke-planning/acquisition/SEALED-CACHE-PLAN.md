# Native sealed cache admission

Authorized by the parent on 2026-10-28T02:55:45. This increment stages contracts and discriminating mocks only. App copies, production changes and NUKE require fresh parent grants. Session audit completion remains denied; this document is local implementation planning, not a replacement session log.

`ISealedSourceCache` extends the existing `ISourceCache`. It reuses `SourceCacheRequest`, with `RecordsJson` ignored by lookup. The lookup returns verified declaration array bytes, the native receipt, and the admitted seal. The extraction facade therefore needs no gzip or sidecar codec. `SourceCacheSeal` contains exact data and sidecar `StoredArtifact` pins and a record count supplied by a trusted native generation index. Computing a new seal from editable cache files does not establish trust and is outside this admission boundary.

Lookup validates the request's native producer, code files, runtime, kind, recipe, source, profile and historical byte policy. It checks exact sidecar SHA and length before deserializing or reading the gzip. It then checks receipt identity, count, exact gzip SHA and length, strict historical policy and the existing bounded JSONL decoder. It does not inspect caller records, extract sources, write artifacts, repair a cache or relabel a Python producer. Malformed seals use CACHE_SEAL; sidecar byte mismatch uses CACHE_SIDECAR_HASH; gzip byte mismatch uses CACHE_HASH; mismatched native identity uses CACHE_IDENTITY; count and wire violations use CACHE_RECORDS. Missing files remain FileNotFoundException. Cancellation remains OperationCanceledException. Shared strict JSON diagnostics are retained for malformed JSON.

Publication returns receipt plus exact stored data and sidecar pins. Old WriteAsync returns the same receipt through one shared publication implementation, preserving its existing errors, gzip bytes, immutable reuse and compatibility fixtures. A sidecar is the last write. Reuse returns the same pins and performs zero writes. A mismatch preserves originals; callers must choose a fresh generation.

BDPv4 order: copy and run the contract mock unit; retain correct and individual property/error/interaction negative-control evidence; implement the shared engine only after the green mock gate; bind the same cases to SourceCache and the recording immutable artifact store; run existing cache tests as regression. No network or extractor is part of this increment. Historical caches remain verified-unused unless separately admitted by a compatible contract.

The Source owner retains the factory/dispatcher and single SourceExtract composer. See `../source/SOURCE-CLI-CACHE-CALLABLE-MAP.md`. A caller without a trusted native index extracts raw input, calls PublishAsync once in a fresh generation, and records the returned seal plus separately owned Java metadata in that generation index. This increment neither invents a second recipe row model nor registers a second operation.
