## Preimplementation streaming correction and required branch packets

Root explicitly acknowledged the strict JSON boundary above. Before observer implementation, source inspection found that PinnedArtifactReader/FileArtifactStore.ReadAsync returns a whole byte array/ReadOnlyMemory and therefore has an inherited Int32/allocation ceiling. At that diagnosis no production observer existed. It must not silently inherit that whole-file ceiling or claim an unbounded reviewer stream. The decision-complete revision composes the existing IStreamingArtifactReader.OpenReadAsync, existing ContentHash.Sha256(Stream), a rewind of the same admitted seekable regular-file stream and incremental per-line classification with Int64 counts, then ObserveCurrentPathAsync. Native per-line JSON capability failure is explicit; no artifact/elapsed/line-count cap, truncation, partial sealing or acceptance is introduced. A streaming pinned session on the existing Core authority was also considered if Root determined pin admission must remain centralized there. No competing pin/hash/IO engine is authorized.

The pure classifier can be incremental over caller-supplied lines; a small-memory adapter is a local convenience, never a whole-stream cap or completeness authority.

Root subsequently approved this streaming revision explicitly before implementation. The original whole-array observer paragraph is superseded, and its diagnosis remains retained.
