## Locked responsibility split

Sources owns one ISourcesExtractOperation and one ISourceExtractGenerationReader. The existing Publication projection is the only recipe/source-row parser. The generation reader admits the caller's exact trusted index SHA256/length before parsing it, then verifies the selected projection, producer/profile/context and each sealed cache identity through the sole ISealedSourceCache SPI. Catalog must not implement cache lookup, decode gzip/sidecars, parse a rehydration recipe or infer a route by extension.

Generation publication is cache-only. CacheSourceLimit counts selected logical cache-producing rows under the preserved legacy rule, independently of deduplicated physical source selection. Noncached or unindexed rows still resolve through the SAME Source facade ResolveAsync path. Catalog has no raw fallback beside it. A verified cache hit skips raw source reads and extraction, including when the consumer's raw file does not exist. A miss/raw route is extracted only by that facade and retains a separate native producer identity.

The bounded Source contract has SourceExtractGenerationRequest(projection, profile, producer, nullableTrustedIndex, optionalJava), an IDisposable admitted generation with ReadAsync(row), and SourceExtractRow carrying RowIndex, SourceLength, actual SourceContext, canonical declaration-array RecordsJson, structural status, issues, metadata, optional sealed RawSourceBase64, cache receipt/seal and CacheHit. The SAME SourcesExtractService also implements ISourceExtractResolver.ResolveAsync(SourceExtractResolveRequest). Its proposed first constructor is (rawSources, generations, runtimes, sealedCache, canonical); the writer and common Core generation adapter follow in that same facade. No competing generation protocol is introduced. Exact API pins will be recorded before the mock copy; source-owned templates changed while outside the app and earlier versions are not immutable evidence.

The authoritative capability set is sdk-api-index and java-source only when the actual admitted Java provider is registered. Other providers are noncache. Flags come from those same runtime provider descriptors, not an independent map in Catalog. The consumer mocks use the original five-source SourceIntegration fixture: base ten declarations, three Java declarations (package, class and method) and three SDK index declarations, with seventeen raw records including the manifest fact. The original java_source.py line109 and native JavaSourceExtractor line37 both explicitly emit that package declaration; it is a separate java-source identity from the signature package.
